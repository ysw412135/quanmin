# 全民经方中医 · 公益 V2 开发线

当前主底座：**Global V1 三语测试版 · 方证优化版（2026-09-13）**  
当前开发方向：**公益 V2（2026-10-01 起）**

这是一个面向普通用户的中医就诊信息整理工具。用户可以先用自己的话描述不适，系统通过动态追问整理事实，并生成便于专业中医快速阅读的症状摘要；公益 V2 开始增加处方照片整理、逐味确认、复诊追踪等诊后能力。

## 当前能力

- 简体中文、繁体中文、English 三语症状整理界面
- 模糊主诉识别与常见问题入口
- FDE Episode 动态追问引擎
- 紧急情况优先筛查
- 症状事实、待核实信息与就诊前摘要
- 方证候选匹配及支持点、缺失点、反证展示
- PWA 离线缓存；无需注册，症状记录仅保存在用户本机
- 公益 V2 处方整理原型：拍照/选图、本地预览、逐味确认、生成文字记录

## 仲景经典来源规则

产品中以“经典方、经方候选、建议经方、方证参考”等形式展示的具体经典方剂，方剂来源只允许：

- 《伤寒论》
- 《金匮要略》

后世解释、医生实际加减和系统推理必须与仲景原典分层展示，不得伪装成原书内容。详见 `PROJECT_GONGYI_V2.md`。

## 处方功能当前状态

`prescription.html` 是本地优先的流程原型：

1. 拍照/选择处方照片；
2. 本地预览；
3. 人工录入或粘贴识别草稿；
4. 逐味确认药名、剂量、用法；
5. 生成可复制的处方整理记录。

当前版本**没有把处方照片发送到外部 OCR 或多模态 AI**。在数据流向、隐私及医疗边界完成审查之前，不接入外部识别服务。

## 文件结构

```text

formula-matcher.js     方证候选匹配器
trees.js               经典经方决策树数据
prescription.html      处方拍照/逐味确认原型
PROJECT_GONGYI_V2.md   公益 V2 执行基线与硬规则
manifest.json          PWA 配置
sw.js                  离线缓存
```

## 本地运行

本项目是纯静态网页，不需要安装依赖：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

症状整理：`/index.html`  
处方整理：`/prescription.html`

## 数据与隐私

当前版本没有账号系统、服务器会话或外部 API。症状问答状态写入浏览器本地存储；处方照片仅用于当前页面本地预览，不做持久化上传。

## 使用边界

本工具用于就诊信息整理与经典经方知识参考。公开测试阶段不自动生成药味增减、剂量调整，也不对医生处方作“对/错”结论。涉及实际诊疗与用药，应由具备相应资质的医师结合患者实际情况判断。

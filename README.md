# 全民经方中医 · 方证优化版

当前版本：**Global V1 三语测试版 · 方证优化版（2026-09-13）**

这是一个面向普通用户的就诊前症状表达工具。用户用自己的话描述不适，系统通过动态追问整理事实，并生成便于专业中医快速阅读的症状摘要；同时提供经典经方方证的学习参考。

## 当前能力

- 简体中文、繁体中文、English 三语界面
- 模糊主诉识别与常见问题入口
- FDE Episode 动态追问引擎
- 紧急情况优先筛查
- 症状事实、待核实信息与就诊前摘要
- 方证候选匹配及支持点、缺失点、反证展示
- PWA 离线缓存；无需注册，记录仅保存在用户本机

## 文件结构

```text
index.html          页面入口与界面样式
app.js              交互、三语文案与本地状态
fde-engine.js       动态预问诊与摘要引擎
formula-matcher.js  方证候选匹配器
trees.js            经典经方决策树数据
manifest.json       PWA 配置
sw.js               离线缓存
```

## 本地运行

本项目是纯静态网页，不需要安装依赖：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 数据与隐私

当前版本没有账号系统、服务器会话或外部 API。问答状态写入浏览器本地存储，不需要 API Key、密码或访问令牌。

## 使用边界

本工具用于就诊前症状表达和经典经方知识学习，不提供医疗诊断或处方。涉及用药，应由执业中医师面诊决定。

# 全民经方中医 · 公益 V2 开发线

当前主底座：**Global V1 三语测试版 · 方证优化版（2026-09-13）**  
当前开发方向：**公益 V2（2026-10-01 起）**

这是一个面向普通用户的中医就诊信息整理工具。用户用自己的话描述不适，系统通过动态追问整理事实，并生成便于专业中医快速阅读的症状摘要；同时提供可追溯的仲景经典方证学习参考，并支持把前后两次症状变化整理成复诊摘要。

## 当前能力

- 简体中文、繁体中文、English 三语症状整理界面
- 模糊主诉识别与常见问题入口
- FDE Episode 动态追问引擎
- 紧急情况优先筛查
- 症状事实、待核实信息与就诊前摘要
- 方证候选匹配及支持点、缺失点、反证展示
- 复诊变化记录：对照上次本机症状记录，整理改善、未变、新出现症状及当前严重度
- PWA 离线缓存；无需注册，症状和复诊记录仅保存在用户本机

## 仲景经典来源规则

产品中以“经典方、经方候选、建议经方、方证参考”等形式展示的具体经典方剂，方剂来源只允许：

- 《伤寒论》
- 《金匮要略》

后世解释和系统推理必须与仲景原典分层展示，不得伪装成原书内容。详见 `PROJECT_GONGYI_V2.md`。

## 明确不做

当前公益 V2：

- 不做医院或诊所处方 OCR；
- 不上传、识别或解析其他医生开出的处方；
- 不评价其他医生方子的对错优劣；
- 不拿系统方证候选与医生实际处方做对抗式比较；
- 不自动生成药味增减或剂量调整方案；
- 不把患者“好转/加重”自动归因于某个医生、某张方或某种治疗。

产品主线保持简单：**症状整理 → 仲景方证参考 → 就诊沟通 → 复诊变化整理。**

## 复诊变化记录

`followup.html` 读取用户本机已经完成的 `qj-episodes` 症状记录，让患者选择一次历史记录作为基线，并记录：

1. 总体感觉；
2. 当前最困扰症状严重度；
3. 哪些症状改善；
4. 哪些症状仍在或变化不大；
5. 是否出现新的不适；
6. 睡眠、饮食、活动或日常生活变化；
7. 预设危险信号自述。

生成结果为《复诊症状变化摘要》。系统只整理患者自述事实，不判断治疗效果原因，不评价医生处方。

## 本地运行

本项目是纯静态网页，不需要安装依赖：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

症状整理：`/index.html`  
复诊变化：`/followup.html`

## 数据与隐私

当前版本没有账号系统、服务器会话或外部 API。症状问答状态和复诊变化记录写入浏览器本地存储。当前版本不采集处方照片。

## 使用边界

本工具用于就诊前症状表达、复诊变化整理与经典经方知识参考。涉及实际诊疗与用药，应由具备相应资质的医师结合患者实际情况判断。

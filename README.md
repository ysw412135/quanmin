> 把“哪里不舒服、什么时候开始、伴随什么、哪些情况危险”先说清楚，再去找真正的医生。

## 这是什么？

**一句话介绍：**

全民中医不是“AI 开方器”，而是一套把普通人的自然语言症状，整理成更适合就医沟通的信息，并提供经典经方方证学习参考的工具。

它目前重点解决三个问题：

1. **患者说不清楚**  
   把“难受、胃不舒服、晚上老咳”这类模糊描述，通过动态追问整理成更完整的症状事实。

2. **医生问诊时间有限**  
   输出结构化《就诊前症状摘要》，尽量减少遗漏，让医生更快抓住时间线、主症、伴随症状和危险信号。

3. **普通人看不懂经方体系**  
   在不替代医生诊断和处方的前提下，把经典经方中的方证关系、支持点、缺失点和反证，用更容易理解的方式呈现。

---

## 为什么做这个项目？

很多普通人，尤其是医疗资源不足地区的老人、儿童家庭和异地子女，在真正见到医生之前就有一个现实问题：

> **不知道该怎么把症状说完整，也不知道什么情况需要尽快就医。**

全民中医希望做的是“就诊前的一公里”：

```
用户自然描述
    ↓
危险情况优先筛查
    ↓
动态追问
    ↓
症状事实整理
    ↓
待核实信息 / 矛盾信息
    ↓
《中医就诊前症状摘要》
    ↓
经典经方方证学习参考
    ↓
带着更清楚的信息去找执业医师
```

这个项目当前优先考虑**公益可用性、低门槛和真实帮助**，而不是把普通用户锁进复杂账号、订阅或数据平台。

## 核心设计原则

### 1. 先安全，再辨证

任何可能涉及急症或明显危险的情况，应优先提示线下就医，而不是继续“猜证型”。

### 2. 先整理事实，再做推断

系统尽量区分：

- 用户明确说过的事实
- 系统追问后补充的信息
- 尚未确认的信息
- 前后矛盾的信息
- 方证学习参考

### 3. 方证参考必须允许“反证”

不是只告诉用户“像什么”，也要告诉用户：

- 为什么像
- 还缺什么
- 哪些表现与它不一致

### 4. 不把工具包装成医生

项目目标是提高就医前的信息质量和经方学习效率，而不是替代执业医师完成诊断、处方和急症处理。

## 使用边界

**本项目不能替代医生。**

当前版本用于：

- 就诊前症状整理
- 医患沟通辅助
- 经典经方知识学习
- 方证匹配的研究与教育参考

当前版本不承诺：

- 医疗诊断
- 疾病确诊
- 个体化处方
- 用药剂量
- 疗效保证
- 急症处理

如出现呼吸困难、意识异常、持续高热、剧烈疼痛、严重脱水、明显出血、抽搐等危险情况，应优先寻求线下医疗帮助。

## 项目方法

当前项目逐步把“中医问诊”拆成可检查的知识工程步骤，而不是把所有判断塞进一个黑箱提示词。

核心方向包括：

```
症状事实
→ 红旗筛查
→ 动态追问
→ 六经八纲 / 方证结构化
→ 支持证据与反证
→ 摘要生成
→ 人工/医生复核
```

长期目标是把每一条规则都变成：

> **可追溯来源 → 可测试规则 → 可被真实案例推翻或修正 → 可持续迭代**

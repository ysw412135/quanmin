# 原典语料层

本层只存有明确版本与版权状态的文本索引。不要将网络上未经校勘的文本直接称为“仲景原文”。

## 条目规范

- `source_id`：唯一编号，示例 `SHL-EDITION-TBD`
- `work`：《伤寒论》或《金匮要略》
- `edition`：校勘版本及出版信息，未核对填 `TBD`
- `location`：篇章/条文/页码；不同版本条号可能不同
- `quotation`：短引文或自有版权的完整文本
- `rights`：公版、授权、未核实
- `verified_by`、`verified_at`

禁止把AI生成的转述伪装成原文，也不要录入未授权的现代注本全文。

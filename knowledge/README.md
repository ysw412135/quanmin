# 全民中医 · 经方知识工程

> 状态：框架 V0.1。这里是知识与证据的结构，不是已经验证的诊断系统。

## 目标

将《伤寒论》《金匮要略》等经典文献中的文本、条文、症状概念、六经八纲、方证线索、方剂、证据来源和验证记录组织成可追溯的知识库，供就诊前症状整理、医学教育及人工审校使用。

## 知识流

```text
典籍来源 corpus
   ↓ 可核对的版本/篇章/条文
症状概念 symptoms ──→ 术语同义词与归一化
   ↓
六经八纲辨证框架 frameworks（假说，不等于患者诊断）
   ↓
方证规则 patterns（包含支持/缺失/反证）
   ↓
方剂索引 formulas（只做文献索引，不生成患者处方）
   ↓
证据台账 evidence ──→ 测试病例 cases
   ↓
规则评审 review ──→ Skill 手册 skills
```

## 发布闸门

所有新条目默认 `draft`。人工核对原典后可转 `text-verified`；执业中医师审校后可转 `expert-reviewed`；经过预注册测试、病例外部验证才能标为 `validated`。**不得因为 AI 自评通过就提升等级**。

每个结论必须记录来源、版本、条文定位、置信边界、反证、审核人和日期。引用二手研究需单独记录；胡希恕等现代解释不可混作《伤寒论》原文。

## 使用边界

知识库不提供个体诊断、药品剂量、停药建议或急症排除。遇危险征象优先转线下医疗，不应继续算法匹配。孕产妇、儿童、老人和慢病用药者应走更严格审查。

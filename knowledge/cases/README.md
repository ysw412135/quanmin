# 病例验证层

**不要提交任何可识别患者的病历、处方照片、姓名、联系方式、面孔、地址或其他敏感健康信息。**

公开仓库只存人工编造的合成案例（明确标记 `synthetic`）或经过合法授权、严格去标识化并完成公开风险评估的数据。

## 最低测试矩阵

- 红旗症状应终止自动方证引导并提示紧急就医。
- 模糊主诉能够继续问关键事实。
- 明确否认 / 未问到 / 肯定存在应被区分。
- 自相矛盾的信息应该追问或交给医生，而不是擅自定论。
- 经方候选的支持/反证应按既定规则如实呈现。
- 低风险答案不能覆盖高风险事实。
- 盲审中记录漏报、误报和信息误填。

评估指标：红旗漏拦截率、信息遗漏率、错误推断率、矛盾处理正确率、盲审一致性。样本规模不足时不宣称“准确率”或临床有效性。

参见仓库现有 `fde/assets/Golden_Test_Set.json` 和 `fde/assets/Synthetic_Patients.jsonl`；纳入前仍须复核其合成性和隐私状态。
